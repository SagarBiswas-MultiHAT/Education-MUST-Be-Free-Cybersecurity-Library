# 📘 Foundations / General Cybersecurity & Mindset

Entry-level guides covering security terminology, operational methodologies, compliance frameworks, and ethical hacking workflows.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. The Cybersecurity Playbook by Allison Cerra
- **Focus**: High-level security strategy, risk governance, defender mindset, and operational workflows.

#### 2. The Basics of Hacking and Penetration Testing by Patrick Engebretson
- **Focus**: Step-by-step introduction to offensive testing phases (reconnaissance, scanning, exploitation, reporting).

#### 3. Ethical Hacking: A Hands-on Introduction to Breaking In by Daniel G. Graham
- **Focus**: Lab-based introduction using virtual machines, Nmap, Metasploit, Wireshark, and basic scripting.

---

### 🟡 Intermediate Level

#### 4. CEH v10 by Ric Messier
- **Focus**: Broad overview of security domains, certification alignment, vulnerability types, and security controls.

#### 5. Ethical Hacking: Techniques, Tools, and Countermeasures by Michael G. Solomon & Sean-Philip Oriyano
- **Focus**: Offensive techniques paired with corresponding defensive countermeasures and security policies.
