# 🌐 Browser & Client-Side Security

Client-side execution contexts, DOM manipulation, Cross-Site Scripting (XSS), Same-Origin Policy (SOP), CORS, and browser extension security.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. HTML, CSS: Design and Build Websites by Jon Duckett
- **Focus**: DOM structure, inline script placement, CSS selectors, and client-side web rendering.

---

### 🟡 Intermediate Level

#### 2. HTML5 Canvas by Steve Fulton & Jeff Fulton
- **Focus**: Canvas API context, client-side data rendering, script execution vectors within 2D/3D graphical elements.

#### 3. The Web Application Hacker's Handbook by Dafydd Stuttard & Marcus Pinto & XSS Sheet by Rodolfo Assis
- **Focus**: Client-side attack vectors, DOM-based XSS, session hijacking, cookie flags (`HttpOnly`, `SameSite`, `Secure`), and payload crafting.

---

### 🔴 Advanced Level

#### 4. The Browser Hacker's Handbook by Wade Alcorn et al.
- **Focus**: Central authority on browser engine internals, JavaScript engine exploitation, sandbox escapes, BeEF framework, WebRTC IP leakage, and extension security.
