# Security Policy

## Reporting Security Issues or Content Concerns

The **Awesome Cybersecurity Books** repository is a curated list of educational resources, guides, and learning roadmaps. It does not contain executable code, services, or deployed applications.

### Copyright & Content Concerns
If you are an author or copyright holder and have concerns regarding any listed resource or linked material:
- Please open an Issue on GitHub or contact the repository owner directly.
- Valid requests regarding content permissions, copyright, or link removals will be addressed promptly.

### Security Disclosures
If you discover security issues related to repository workflows or link integrity:
- Please report them by opening a GitHub Issue or reaching out via GitHub.

Thank you for helping keep this community resource safe and legal!
