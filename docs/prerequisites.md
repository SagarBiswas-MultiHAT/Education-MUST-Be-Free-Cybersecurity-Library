# 🔰 Supporting & Prerequisite Resources

Core foundations in programming, operating systems, networking, and web development necessary before tackling advanced security concepts.

---

## 📚 Curated Resource Sequence

### 🟢 Beginner Level

#### 1. Python Crash Course by Eric Matthes
- **Focus**: Building your core Python scripting base.
- **Key Concepts**: Variables, lists, loops, functions, classes, basic file I/O.

#### 2. Python Notes for Professionals by GoalKicker / Community
- **Focus**: Quick-reference companion while practicing Python scripts.

#### 3. Linux Basics for Hackers by OccupyTheWeb
- **Focus**: Command-line interface, permissions, package management, shell basics, and networking utilities.

#### 4. CCNA 200-301 Official Cert Guide by Wendell Odom
- **Focus**: Network fundamentals, TCP/IP vs OSI model, IP addressing, subnetting, routing, and switching.

#### 5. HTML & CSS: Design and Build Websites by Jon Duckett
- **Focus**: Visual and structural web fundamentals to understand web application presentation layers.

---

### 🟡 Intermediate Level

#### 6. The C Programming Language (2nd Edition) by Kernighan & Ritchie
- **Focus**: Systems-level literacy, memory pointers, struct definitions, compile-time operations.

#### 7. C++ for Hackers by Steve Oualline
- **Focus**: Object-oriented concepts and C++ memory management with a security perspective.

#### 8. Linux Command Line and Shell Scripting Bible by Richard Blum & Christine Bresnahan
- **Focus**: Bash scripting automation, text processing (awk, sed, grep), process management.

#### 9. TCP/IP in C by Michael J. Donahoo & Kenneth L. Calvert
- **Focus**: Network socket programming in C, client-server interaction models.

#### 10. HTML5 Canvas by Steve Fulton & Jeff Fulton
- **Focus**: Interactive web graphics and client-side script execution context.

---

### 🔴 Advanced Level

#### 11. Linux System Programming by Robert Love
- **Focus**: System calls, kernel I/O, memory mapping (mmap), process signals, and thread synchronization.
