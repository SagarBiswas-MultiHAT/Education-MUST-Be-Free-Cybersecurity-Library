# 🛡️ Defensive Security & Incident Response

Detailed curriculum for network security monitoring, threat hunting, incident response, and SOC operations.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. The Cybersecurity Playbook by Allison Cerra
- **Focus**: Defensive operations, IR planning, risk management, and security architecture.

---

### 🟡 Intermediate Level

#### 2. The Practice of Network Security Monitoring by Richard Bejtlich
- **Focus**: Packet analysis, intrusion detection (Zeek/Suricata), SOC workflows, and continuous monitoring.

---

### 🔴 Advanced Level

#### 3. Pair with Malware Dissection & AV Research
- **Focus**: End-to-end incident investigation pairing network monitoring with binary forensic analysis.
- **Recommended Reading**: [Practical Malware Analysis](malware-analysis.md) and *The Antivirus Hacker's Handbook*.
