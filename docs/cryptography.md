# 🔐 Cryptography & Applied Security

Mathematical foundations, symmetric and asymmetric ciphers, public key infrastructure (PKI), and cryptographic implementation in C/C++.

---

## 📚 Curated Book Sequence

### 🟡 Intermediate Level

#### 1. Cryptography in C and C++ (2nd Edition) by Michael Welschenbach
- **Focus**: Algorithmic implementation of AES, RSA, ECC, hash functions, and multiprecision arithmetic in C and C++.

---

### 🔴 Advanced Level

#### 2. Applied Cryptography by Bruce Schneier
- **Focus**: The definitive treatise covering cryptographic protocols, block ciphers, key management, digital signatures, and real-world implementation pitfalls.
