# 🛠️ Scripting, Tooling & Automation

Automating offensive and defensive security operations using Python, Bash, and shell scripting.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. 50 Useful Python Scripts by GoalKicker / Community
- **Focus**: Practical, ready-to-use Python snippets for file parsing, HTTP requests, port checks, and text extraction.

#### 2. Python Crash Course by Eric Matthes
- **Focus**: Core Python syntax, data structures, functions, modules, and basic scripting automation.

#### 3. Python Notes for Professionals by GoalKicker / Community
- **Focus**: Reference manual for Python standard libraries (`os`, `sys`, `re`, `subprocess`, `socket`).

#### 4. Coding Games in Python by DK Publishing
- **Focus**: Practice-heavy reinforcement for building interactive scripts and game logic.

---

### 🟡 Intermediate Level

#### 5. Black Hat Python by Justin Seitz & Tim Arnold
- **Focus**: Creating custom security tools in Python — raw sockets, Scapy packet sniffing, Web Trojan crafting, Windows privilege escalation.

#### 6. Black Hat Bash by Dolev Farhi & Nick Aleks
- **Focus**: Offensive and defensive shell scripting, command-line one-liners, SSH tunnels, parsing log files, and automation pipelines.

#### 7. Python Complete Notes by QuantInsti
- **Focus**: Data analysis, regex string manipulation, automated reporting, and scripting optimization.
