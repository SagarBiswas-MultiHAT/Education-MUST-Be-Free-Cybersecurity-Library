# 📱 Mobile Application Security

Detailed guide for auditing Android and iOS application attack surfaces, dynamic instrumentation, IPC mechanisms, and mobile malware dissection.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. Hacking Android by Srinivasa Rao Koti
- **Focus**: Setting up Android testing environments, ADB usage, basic application decompilation, and vulnerability analysis.

---

### 🟡 Intermediate Level

#### 2. The Mobile Application Hacker's Handbook by Dominic Chell et al.
- **Focus**: Complete assessment methodology for Android and iOS apps, local storage analysis, SSL pinning bypass, IPC flaws.

#### 3. The Android Malware Handbook by Qian Han et al.
- **Focus**: Dissecting Android APKs, dynamic instrumentation with Frida, unpacking obfuscated samples, and reverse engineering.

---

### 🔴 Advanced Level

#### 4. Android Hacker's Handbook by Joshua J. Drake et al.
- **Focus**: Deep Android OS internals, Stagefright vulnerabilities, binder IPC, kernel drivers, and exploit development.
