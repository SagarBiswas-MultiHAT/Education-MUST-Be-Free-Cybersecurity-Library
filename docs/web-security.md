# 🌐 Web Application Security & Bug Bounties Study Guide

A dedicated domain guide covering web vulnerability assessment, client-side security, database exploitation, and bug bounty hunting methodology.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. Web Hacking 101 by Peter Yaworski
- **Focus**: Intro to web vulnerabilities through real-world bug bounty reports.
- **Key Concepts**: XSS, CSRF, IDOR, SQLi, Open Redirects.
- **Companion Practice**: [PortSwigger Web Security Academy](https://portswigger.net/web-security) (Free).

#### 2. All About SQL
- **Focus**: Relational database fundamentals.
- **Key Concepts**: Queries, joins, schema structure, data manipulation.

---

### 🟡 Intermediate Level

#### 3. Real-World Bug Hunting by Peter Yaworski
- **Focus**: Modern web attack surfaces and bug bounty strategies.
- **Key Concepts**: Subdomain enumeration, SSRF, XXE, OAuth vulnerabilities, API testing.

#### 4. The Web Application Hacker's Handbook by Dafydd Stuttard & Marcus Pinto
- **Focus**: The definitive methodology for web app penetration testing.
- **Key Concepts**: Session management, access controls, input validation, logic flaws.

#### 5. OWASP Testing Guide (v4)
- **Focus**: Standardized security assessment checklists.

#### 6. Blind SQL Injection by Kevin Spett
- **Focus**: Advanced database exploitation under constrained feedback conditions.

---

### 🔴 Advanced Level

#### 7. The Browser Hacker's Handbook by Wade Alcorn et al.
- **Focus**: Browser sandboxing, DOM exploitation, CORS bypasses, WebRTC leakage.

#### 8. Advanced SQL Injection by Justin Seitz
- **Focus**: WAF evasion, out-of-band data exfiltration, database finger-printing.

#### 9. XSS Sheet by Rodolfo Assis
- **Focus**: Comprehensive payload craft and context-aware script injection.
