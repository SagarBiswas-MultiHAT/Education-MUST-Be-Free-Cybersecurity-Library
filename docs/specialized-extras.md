# 🧰 Specialized & Miscellaneous Extras

Productivity guides, technical interview prep, vulnerability research extras, and specialized toolsets.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. VS Code Shortcuts by Microsoft Docs / Community
- **Focus**: Keybindings, multi-cursor editing, workspace navigation, debugging workflows, and editor productivity.

#### 2. Top 40 Python Interview Questions & Answers by Community Reference
- **Focus**: Core Python technical interview preparation for security developers, automation engineers, and junior analysts.

---

### 🟡 Intermediate Level

#### 3. Real-World Bug Hunting by Peter Yaworski & Web Hacking 101 by Peter Yaworski
- **Focus**: Real-world vulnerability write-ups, disclosure methodologies, bounty program navigation, and practical bug hunting.

#### 4. Metasploit: The Penetration Tester's Guide by David Kennedy et al. & The Hacker Playbook 3 by Peter Kim
- **Focus**: Offensive toolset runbooks, post-exploitation modules, C2 setup, and structured penetration testing methodologies.

---

### 🔴 Advanced Level

#### 5. The Antivirus Hacker's Handbook by Joxean Koret & Elias Bachaalany & The Art of Computer Virus Research and Defense by Peter Szor
- **Focus**: Security software research, AV engine fuzzing, disassembler design, virus propagation theory, and kernel driver analysis.
