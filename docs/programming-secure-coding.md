# 💻 Programming & Secure Coding

Systems programming literacy in C and C++, safe memory management, input sanitization, and data structures.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. The C Programming Language (2nd Edition) by Kernighan & Ritchie
- **Focus**: Pointers, arrays, structures, file I/O, memory allocation (`malloc`/`free`), standard library functions.

#### 2. Programmer's Guide to NCurses by Dan Gookin
- **Focus**: Building terminal-based user interfaces and console applications in C.

---

### 🟡 Intermediate Level

#### 3. C++ for Hackers by Steve Oualline
- **Focus**: OOP concepts, references vs pointers, STL containers, safe string handling, security-oriented C++ design.

#### 4. Best Book to Master C++ Programming by Bjarne Stroustrup
- **Focus**: Comprehensive reference on modern C++ standards, RAII, move semantics, smart pointers (`unique_ptr`/`shared_ptr`).

#### 5. Sockets in C by Panagiota Fatourou & Eleftherios Kosmas
- **Focus**: Safe network I/O, socket buffer management, multi-client server architecture.

---

### 🔴 Advanced Level

#### 6. Advanced Data Structures in C++ by Peter Brass
- **Focus**: Algorithmic efficiency, balanced search trees, heaps, priority queues, and low-level memory footprint optimization.
