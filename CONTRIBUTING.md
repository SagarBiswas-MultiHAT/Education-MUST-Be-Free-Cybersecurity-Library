# Contributing to awesome-cybersecurity-books

Thank you for taking the time to contribute! This community-driven library aims to provide accessible, high-quality, non-paywalled cybersecurity learning paths for self-study.

---

## 🚀 How to Contribute

### 1. Suggesting a New Book or Resource
If you know of a high-quality cornerstone book or resource missing from this collection:
- Open an Issue using the **"📚 Suggest a Book"** template.
- Ensure the book fits within one of the existing 14 domain categories or propose a new section.
- Indicate the appropriate difficulty level (🟢 Beginner, 🟡 Intermediate, 🔴 Advanced).
- Provide a brief 1–2 sentence summary explaining *why* it belongs in the curriculum.

### 2. Reporting a Broken Link or Outdated Resource
If you notice a broken link, missing Google Drive entry, or outdated edition:
- Open an Issue using the **"🔗 Report a Broken Link"** template.
- Provide the section title, book name, and nature of the issue.

### 3. Improving Content or Formatting
For typos, markdown formatting fixes, or adding companion lab recommendations:
- Submit a Pull Request directly or open an Issue using **"✏️ Improve Content / Fix Typo"**.

---

## 📜 Entry Style Guide

When adding or updating book entries in the README, follow this strict format:

```markdown
- [Difficulty Emoji] **Title** by Author(s) — Brief 1-sentence value proposition explaining what key concept is learned.
```

### Difficulty Emojis:
- 🟢 **Beginner**: Requires minimal prior knowledge in cybersecurity or programming.
- 🟡 **Intermediate**: Requires basic understanding of networking, Linux/OS, or programming.
- 🔴 **Advanced**: Low-level internals, complex exploit development, advanced reverse engineering.

---

## 🛠️ Pull Request Checklist

Before submitting a Pull Request:
- [ ] Check if the book or resource is already listed in another section.
- [ ] Ensure formatting strictly matches the Entry Style Guide.
- [ ] Make sure link URLs are accurate and accessible.
- [ ] Maintain consistent section numbering and difficulty progression (Beginner -> Intermediate -> Advanced).
