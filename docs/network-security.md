# 📡 Network Security & Monitoring

Guide for traffic analysis, protocol inspection, intrusion detection systems, packet analysis, and network socket programming.

---

## 📚 Curated Book Sequence

### 🟢 Beginner Level

#### 1. CCNA 200-301 Official Cert Guide by Wendell Odom
- **Focus**: Network fundamentals, subnetting, TCP/UDP headers, switching, routing, and access control lists (ACLs).

---

### 🟡 Intermediate Level

#### 2. The Practice of Network Security Monitoring by Richard Bejtlich
- **Focus**: Full packet capture (FPC), Security Onion deployment, Zeek/Suricata analysis, SOC workflows, and detection engineering.

#### 3. TCP/IP in C by Michael J. Donahoo & Kenneth L. Calvert
- **Focus**: Low-level network programming, sockets API, custom TCP/UDP client and server implementations.

#### 4. Sockets in C by Panagiota Fatourou & Eleftherios Kosmas
- **Focus**: Network socket programming patterns, non-blocking I/O, raw sockets, and packet crafting utilities.
